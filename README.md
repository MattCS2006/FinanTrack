# FinanTrack

## Goal:

App móvil simple para trackear finanzas personales, con opción básica de cuentas para separar personal/proyectos. Resuelve desorden financiero con UI intuitivo.

## Tech Stack

- **React Native**

- **Expo**

- **TypeScript**

- **Supabase**

## Installation

### Prerequisites

- Node.js (versión 20.x o superior)
- Git
- Expo Go app en tu teléfono para testing

### Steps

1. Clona el repo: `git clone https://github.com/tuusuario/FinanTrack.git`
2. Navega a la carpeta: `cd FinanTrack`
3. Instala dependencias: `npm install`
4. Configura .env con tus Supabase keys
5. Corre la app: `npx expo start`
